# Резервная копия при обновлении пакета

По умолчанию установщик сохраняет копию для отката в
`/opt/tmp/optiray-opkg-state`, на накопителе `/opt`, а не в RAM-разделе `/tmp`.
Свободное место проверяется на разделе выбранного каталога с запасом 8 МБ.

Другой абсолютный путь можно передать при установке или обновлении:

```sh
OPTIRAY_BACKUP_DIR=/opt/custom-backup/optiray-opkg-state opkg upgrade optiray
```

Выбранный путь записывается в `/opt/var/lib/optiray/opkg-backup-path`.
Повторный запуск настройки использует этот путь, даже если переменная окружения
уже не передана. Каталог внутри установки OptiRay и каталог, содержащий саму
установку, использовать нельзя.

Копия содержит предыдущие файлы приложения, бинарники, настройки, подписки,
правила, пользовательские резервные копии правил и служебные скрипты.
Каталоги `log`, `logs`, `cache`, `tmp`, `run`, файлы `*.log`, `*.log.*`,
`*_cache.json`, `engine.pid` и `engine.sock` в неё не включаются.
Исключение из копии не удаляет пользовательские файлы из рабочей установки.

После успешной проверки новой версии копия и указатель удаляются.
При ошибке копия сохраняется. Новое обновление не перезаписывает незавершённую
копию: сначала необходимо восстановить или сохранить её отдельно.
Старый каталог `/tmp/optiray-opkg-state` также блокирует новую установку,
чтобы не потерять данные восстановления от предыдущих версий.
