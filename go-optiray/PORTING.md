# OptiRay Go: состояние переноса

Перенос функций Python 4.0.2 реализован в отдельной поставке Go
`1.0.5`. Это кандидат для испытаний, а не объявление стабильного
релиза. Рабочая Python-установка сохранена и восстановлена после проверки.

## Реализовано

- Подписки: HTTP/gzip/base64, HWID, профили Happ/Incy/OptiRay, обновление,
  миграция старых данных, стабильные SID и восстановление выбранного сервера.
- VLESS, VMess, Trojan, Shadowsocks, SOCKS, HTTP, WireGuard; составные Xray
  конфигурации, balancer, DNS, observatory, TLS pinning и Hysteria.
  TUIC/AnyTLS отображаются как неподдерживаемые, запуск не имитируется.
- Избранное, порядок подписок, ручная сортировка, закрепление активного сервера
  внутри подписки. Подключение не переставляет саму подписку.
- Xray и Hysteria: собственные процессы, проверка конфигурации и занятого порта,
  откат запуска, восстановление после сбоя, HTTP-прогрев через SOCKS с remote DNS.
- TCP/HTTP-пинг, отмена и ограничения параллелизма. Автовыбор использует три
  HTTP-измерения на одном временном ядре и медиану, сохраняет стабильные ничьи.
- Настройки и HTTP Basic: валидация, применение действующего подключения,
  транзакционные записи и восстановление после прерванной записи.
- Резервные копии настроек/Xray/OptiRout, восстановление, сброс и удержание копий.
  При полном сбросе сохраняются HWID и параметры прокси Keenetic.
- Обе модалки маршрутизации, импорт/экспорт XLSX без Python/openpyxl,
  активный лист книги, правила Xray, управление OptiRout, обнаружение интерфейсов.
- OptiRout: отдельные PID/socket/config, DNS и netfilter, переключение режимов,
  перезапуск и возврат прежних правил при ошибке. Нативная передача событий
  firewall не требует socat или Python.
- Keenetic: создание/проверка/переименование прокси, журнал исходного состояния,
  откат и удаление только управляемых интерфейсов. Обновление существующего
  прокси сохраняет его уровень безопасности и административное состояние.
- Поиск релизов, установка/удаление Xray и Hysteria в частный каталог;
  проверка ELF/архитектуры и откат замены файлов.
- Отдельные HTML/CSS/JS, флаги и состояние подключения; изменения интерфейса
  доступны без перекомпиляции сервера.
- Установщик с автоматическими зависимостями, запуском, динамическим LAN-адресом,
  миграцией Python и откатом; служба, firewall hook и удаление Go без установки Python; пакеты ARM64/MIPSel,
  SHA256 и исходники изменённого GPL-ядра OptiRout.
- Все маршруты контракта интерфейса обработаны. Отключённые возможности
  возвращают 503; заглушек 501 нет.

## Границы проверки

ARM64 проверен на реальном Keenetic с текущими настройками и активным сервером.
MIPSel собран с softfloat, но отдельного физического MIPSel-роутера для теста нет.
Нативный Hysteria2 проверен; Hysteria1 требует отдельного `hysteria1` и не проходил
проверку с действующим сервером. Проверка HTTP не заменяет длительные испытания
всех устройств LAN и всех доступных серверов.

`/api/health` пока сообщает `release_ready: false`, поскольку поставка имеет статус
кандидата. Это не признак отсутствующих HTTP-функций. Не запускайте два OptiRout
одновременно; Go отказывается запускать свой движок при PID рабочей установки.

## Проверка исходников

```powershell
& ../research/toolchain/go/bin/go.exe test ./...
& ../research/toolchain/go/bin/go.exe vet ./...
```

Тесты на роутере включаются явно через `OPTIRAY_LIVE_FIXTURE` или
`OPTIRAY_FULL_FIXTURE`; обычные локальные тесты не меняют рабочий роутер.
