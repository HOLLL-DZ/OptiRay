OptiRay Routing

По одному правилу в строке. Определяется автоматически: example.com → домен, *.ru → суффикс, 1.2.3.0/24 → IP-сеть, 1.2.3.4 → IP, 1.2.3.4-1.2.3.10 → диапазон IPv4, 2001:db8::/32 → IPv6-сеть. Можно задать явно: domain:, full:, regexp:, geosite:, geoip:. Строки с # — игнорируются.
