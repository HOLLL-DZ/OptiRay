# Безопасность

Не публикуйте уязвимости с действующими ссылками подписок, ключами, HWID, паролями или полными бэкапами.

Используйте приватное сообщение через GitHub Security → Report a vulnerability, если эта возможность включена в репозитории. Если приватный канал недоступен, создайте Issue без технических подробностей и запросите способ приватной передачи.

Укажите версию OptiRay, архитектуру и прошивку Keenetic, шаги воспроизведения и возможное влияние. До публикации исправления не прикладывайте действующие секреты или сведения, позволяющие атаковать чужую установку.

Включайте аутентификацию и используйте интерфейс в доверенной локальной сети. Версия 1.0.2 является тестовым выпуском; SLA и гарантированный срок исправлений не заявлены.
