# Участие в разработке

Разработка ведётся на Go. Перед изменением прочитайте README и ограничения в `go-optiray/PORTING.md`.

1. Создайте ветку для одной задачи.
2. Добавьте проверку поведения, если меняется логика настроек, соединения или маршрутизации.
3. Выполните `go test ./...` и `go vet ./...` в `go-optiray/`.
4. Для сборки пакетов используйте `go-optiray/package.ps1` с PowerShell 7 и Go 1.23.12.
5. В Pull Request опишите проблему, изменение поведения и выполненные проверки. Указывайте, проверялось ли изменение на физическом роутере.

HTML, CSS и JavaScript остаются отдельными файлами. Проверки на роутере выполняйте с отдельным каталогом и портом. Не завершайте чужие процессы Xray, Hysteria или маршрутизации. Сборка и тесты не должны автоматически обновлять рабочую установку.

В коммитах не должно быть ссылок подписок, HWID, ключей, паролей, бэкапов и журналов с личными данными. Изменения стороннего OptiRout должны сохранять исходное авторство и лицензии.
